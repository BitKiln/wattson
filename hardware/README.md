# Measurement hardware

**Status: deferred to phase 7.**

Schematics, PCB layout, and BOM for an open measurement board.

Deliberately last. A v1 aimed at *firmware power analysis* rather than *precision laboratory
instrumentation* is achievable now and stays useful regardless of what board someone eventually
attaches. Automatic uA-to-A range switching, MHz-class acquisition, precision calibration, and a
programmable target supply are all wanted, and all later.
